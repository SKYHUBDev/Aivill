# AiVill Assets

This directory contains logos and branding assets for AiVill.

## Logos

- `aivill-logo.svg` - Vector logo (recommended for web, docs, PyPI)
- `aivill-logo.png` - Rasterized logo (220x220, for compatibility)

## Usage

The logo is displayed on:
- PyPI project page
- GitHub repository
- Documentation (docs/architecture.md, docs/api.md)
